# Roadmap

Six milestones, each delivered end to end in one run. Component IDs (C* in `football-core`,
M* / P* here) stay stable so specs, commits and docs can refer to them. Thresholds come from a
single-season StatsBomb pilot; they are re-baselined once on the final split, then frozen.

| # | Milestone | Components | Done when |
|---|---|---|---|
| 1 | **Data foundation** ✅ | C3 schema, C6 snapshots + manifest CLI (core) | ✅ Shot and freeze-frame tables validate with clear errors; snapshots are byte-identical on rerun and `fc verify` catches a one-byte change |
| 2 | **StatsBomb xG baseline** ✅ | C4 `io.statsbomb`, C7 `viz` (core); M1.0 leakage guard, M1.1 baselines | ✅ 101,614 shots of 3,961 matches load with zero schema violations and goals reconcile with the score in every match (shoot-outs excluded). The allow-list test rejects every C3 column that is not `pre_shot`. Base rate → LR distance + angle → + body part each have a [model card](models/xg-lr-distance-angle-body-part.md). Best (LR + body part), grouped 5-fold CV on 89,929 shots: log loss **0.2880** (target ≤ 0.275, *missed*), Brier **0.0821** (≤ 0.077, *missed*), AUC **0.7628** (≥ 0.75, met), \|Σ xG − goals\| / goals **0.02 %** (≤ 3 %, met); hold-out PL 2015/16 0.2726 / 0.0767 / 0.7548 / 6.98 %. The miss comes from the sample mix: team-selected seasons (one-club collections and single finals) are fitted as well as league or tournament shots (log-loss skill against their own goal rate 0.146 vs 0.145) but convert more (11.90 % goals; 0.3117 log loss), and the pooled geometry model is less skilful on women's shots (skill 0.116; 0.2974). Without the team-selected seasons dev still scores 0.2821 out of fold, above the target: only the men's league or tournament shots meet it (0.2686 / 0.0756). StatsBomb's own xG gets 0.2674 / 0.0758. The pooled CV Σ xG error is near 0 by construction; per fold it is 2.66 % on average (max 3.99 %), and 6.98 % on the hold-out. Reported, not tuned. Shot map and goal-mouth plot pass image tests |
| 3 | **xG model** ✅ | C3.1 matches table (core); M1.2 splines + context, M1.3 freeze-frame features, M1.4 monotone GBM + calibration, M1.5 penalty model | ✅ Targets re-baselined by the PM on the same shots (MS2's 0.258 dropped): beat the MS2 best baseline with a match-bootstrap 95% CI above 0, CV log loss within 0.006 of StatsBomb xG, calibration slope in [0.9, 1.1] (CV, hold-out, men, women), Σ xG error fold mean ≤ 3 % and worst fold ≤ 5 %, GBM only with a CI above 0 over the best LR, penalty point estimate in 0.76–0.80. Population: 99,713 shots after excluding 33 direct corners (dev 89,897 / hold-out 9,816). LR steps, CV log loss: [splines + body part](models/xg-lr-splines.md) 0.2860 → [+ context](models/xg-lr-context.md) 0.2740 → [+ freeze frames](models/xg-lr-frames.md) 0.2673, each gain with a CI above 0. **Headline: [monotone GBM + Platt](models/xg-gbm.md)**, CV log loss **0.2638** (Brier 0.0754, AUC 0.8107), gain over the best LR +0.0035 [+0.0028, +0.0043] and over LR distance + angle + body part +0.0234 [+0.0219, +0.0249]; StatsBomb xG gets 0.2659 on these shots (gap −0.0021, met). Calibration slope CV 1.010, hold-out 0.953, men 1.024 and women 0.984 out of fold, men 0.953 on the hold-out; women on the hold-out n/a (Premier League 2015/16 has no women's shots). Σ xG error fold mean 1.71 % (max 2.92 %). On the hold-out (0.2533) the gain over the best LR, +0.0014 [−0.0005, +0.0034], and over StatsBomb, −0.0013 [−0.0040, +0.0016], include 0, and the GBM predicts 975 goals for 913 (+6.77 %). [Penalties](models/xg-penalty.md): point estimate 0.7627 [95 % interval 0.7374, 0.7872] from 1,118 in-game kicks (inside the window by 0.0027; the interval extends below it); shoot-outs 0.6662 apart. Every model has a card; the README summary lists every model next to StatsBomb xG |
| 4 | **WhoScored xG v1** ✅ | C5 `io.whoscored` (core); M0 legacy v0 score, M1.6 WhoScored model, M1.7 release | Targets: trained on 2025-26, tested on 2026-27 with an asserted date order, non-penalty test log loss ≈ 0.26–0.27 (above 0.275 a miss with its reason), at least as good as v0 on the same test shots with a match-bootstrap 95 % CI on the gain, test calibration slope in [0.9, 1.1], test Σ xG error per competition. **C5** (core): the private archive loads into the C3 shots and matches tables with zero schema violations; one status-first keep rule keeps the duplicated match once whatever the read order and logs every drop; goals reconcile with the score in every scored match (counts in football-core's roadmap). **Results:** every number is in the [xG v1 card](models/xg-v1.md) (Checks, Gains, Test by competition) and the README v1 block, both written by `make xg-v1` and checked byte for byte by `make reproduce`; none is typed here. Two check rows are missed, each with a computed reason line: the test log-loss bound (the criterion allows a miss with a reason) and the gain over the legacy v0, which reads Opta big chance (q214), a column the leakage rule bars from v1. The miss-with-reason clause covers only the log loss, so the PM ruled (2026-10-25): both misses stand as recorded misses, and the v0 element is re-baselined to v0's inputs refitted without q214 (the card's head-over-remove row), whose gain interval lies above 0. No WhoScored row, table or file is committed |

| 6 | **Goalkeepers** | P3.1 GSAx, P3.2 hierarchical keeper model, P3.3 stability study | Keeper totals sum to league Σ PSxG − GA with SDs and 90% CIs; shrunken estimates predict the next season better than raw GSAx; reliability at 100 / 250 / 500 shots faced |
