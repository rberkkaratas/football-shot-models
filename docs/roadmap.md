# Roadmap

Six milestones, each delivered end to end in one run, then a polish round, a chart round and a
docs round.
Thresholds come from a single-season StatsBomb pilot; they are re-baselined once on the final
split, then frozen.

printed by a card or a README block, checked byte for byte by `make reproduce`.

## Chart rounds

Charts drawn from fit objects or the warm prediction cache, never by refitting a model of record.
The StatsBomb example charts are published on the [Charts](charts.md) page with the logo;
WhoScored charts never leave the machine. Charts go to LinkedIn only after Berk approves them.

| Round | Components | Done when |
|---|---|---|
| **Chart round 1: themed chart system, shot charts, keeper and model-card visuals (render only)** ✅ | core `viz` theme layer; `football_shot_charts` (new sibling package outside the cache hash, so chart edits keep the cache warm): `rows`, `shots`, `keepers`, `diagnostics`, `render`; `gsax_cards` (render-only) | ✅ `make charts` (warm cache) writes 18 StatsBomb charts to the git-ignored `outputs/charts`: the team shot chart (`CHART_TEAM`, display name from `--team-name`) and the profile of that team's player with the most kept shots (chosen without reading outcomes), each in light and dark at 1080 × 1350 and 1080 × 1080 px, the keeper (GSAx) chart and the xG and xGOT calibration and model-comparison charts in both themes. It prints `cache: hits [...] written []` and `checks: 0 problems`: no model is refit (the read-only guard turns any cache miss into an error; the uncached estimations, `xgot.fit`'s shoot-out penalty LR and `gsax.fit`'s keeper model, are existing deterministic behaviour, the first pinned by a slow spy at one per provider), and every chart passes `viz.check` (text overlap and clipping, WCAG text contrast 4.5:1 and 3:1 for large text and marks) in both themes before it is written. Titles are computed statements that never name skill; every gap between goals and xG is printed with its SD. StatsBomb charts carry the logo and "Prepared by R. Berk Karataş"; WhoScored charts render only through `make charts-private` into the git-ignored `data/charts/private`. Image baselines on synthetic fixtures for every chart family. No hashed module changed (`source_hash` unchanged), so `make reproduce` stays warm and every card is byte-identical except the [GSAx card](models/gsax.md)'s chart sentence, which now carries the two keeper-chart PNG digests |
