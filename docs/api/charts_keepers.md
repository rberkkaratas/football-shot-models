# charts: keepers

CH1: the keeper (GSAx) chart. The highest and lowest `TOP_N` keeper-seasons by shrunk GSAx per
100 on-target shots with the keeper model's posterior interval and the unshrunk value as a
tick; the title counts the seasons whose interval excludes 0, the subtitle is the reliability
verdict. Keeper names on StatsBomb charts only.
