# v2

WhoScored xG v2, xG v1 plus the pre-shot context columns `prev_action` and `rebound`
(core schema 1.3), on v1's population and season split. `fit` is pure; `census` counts the Opta
qualifiers by class; `v2_checks` are the polish round's v2 checks. Keeper-derived context never enters the
xGOT input chain, so that GSAx keeps the keeper's own credit; v1 stays the WhoScored xGOT input.
