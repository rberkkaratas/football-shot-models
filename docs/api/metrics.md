# metrics

Log loss, Brier, AUC, calibration, reliability bins, the milestone thresholds and split-half
reliability (`split_half`, by alternating matches or rows). The band rule of every Σ p − goals
table (xGOT and GSAx bands, the xG hold-out level) lives here once: `BAND_SDS`,
`poisson_binomial` (the gap and its Poisson-binomial SD), `within` and `MIN_JUDGED_SHOTS`, all
read when called.

::: football_shot_models.metrics
